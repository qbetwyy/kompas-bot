# Компас

Telegram-бот, который помогает готовиться к поступлению и первым собеседованиям. Сделан на конкурс SK Challenge 2026 по кейсу Софтлайн Решения «Цифровое наставничество и AI-менторство», категория Lead.

Попробовать: [@kompaser_bot](https://t.me/kompaser_bot). Если времени мало, отправьте ему `/demo`, за минуту он сам покажет, что умеет.

## Зачем он

В этом году я сам поступал и вижу, на чём спотыкаются ребята вокруг. Правила приёма каждый год немного меняются, и одна пропущенная галочка на Госуслугах стоит бюджетного места. А на первом собеседовании половина людей отвечает «ну, опыта нет, я ничего не умею» и даже не замечает этого.

Компас делает две вещи:

1. **Отвечает на вопросы** про поступление, поиск стажировки и первый месяц на работе. Отвечает только по своей базе из 37 заметок, у каждой есть ссылка на источник (Минобрнауки, Трудовой кодекс, hh.ru и т. д.). Если ответа в базе нет, так и говорит.
2. **Тренирует.** Играет рекрутера, HR или руководителя и задаёт неудобный вопрос. Ты отвечаешь, лучше голосом. Бот разбирает ответ в три части, как просит кейс: «Это верно», «Вот что можно улучшить», «Вот удачный пример ответа», и задаёт уточняющий вопрос.

Чего нет у обычного чат-бота:

- **Он слушает, как ты говоришь.** Голосовое расшифровывается прямо на сервере, с таймкодами слов. По ним бот считает «ну», «типа», «как бы», темп речи и долгие паузы, а в следующий раз показывает, стало ли лучше.
- **Он помнит слабые места.** Ошибки сохраняются, и следующая тренировка начинается именно с них. После тренировки бот присылает карту навыков «было / стало», а весь разбор можно скачать в PDF.
- **Он не выдумывает.** Факты берутся только из базы, а ссылки на источники добавляет код, а не нейросеть.

## Как устроен

- Python, aiogram 3, SQLite.
- Поиск по базе, свой BM25 с русским стеммером. Найденные заметки уходят в Claude (Anthropic API), и модели запрещено отвечать не по ним.
- Типичные ошибки («ничего не умею», «вопросов нет», «предложите сами по зарплате», всего 18 видов) сначала ищут обычные правила, потом модель. Явную ошибку правила не пропустят, даже если модель её не заметила.
- Если API недоступен, бот не ломается: справка показывает заметки из базы, тренажёр оценивает по правилам.
- Голос: faster-whisper локально. Карта навыков: matplotlib. PDF: fpdf2.

Подробнее со схемой, в [ARCHITECTURE.md](ARCHITECTURE.md). Вся база знаний с источниками, в [docs/knowledge_base.md](docs/knowledge_base.md).

## Как проверял

- 15 автотестов, в том числе прогон всего сценария в Telegram без сети (`tests/`).
- Мини-бенчмарк: 42 ответа, которые я разметил вручную. Одни правила без нейросети никогда не придирались к хорошим ответам и нашли верную ошибку в 86% плохих. Набор мой, и правила частично подгонялись под него, так что цифры скорее оптимистичные. Полный прогон с моделью: `python tools/benchmark.py --llm`.
- Симуляция на виртуальных кандидатах (`python tools/simulate.py`, отчёт в [docs/simulation.md](docs/simulation.md)). Кандидат стабильно ошибается в чём-то одном, бот проводит тренировку из 6 вопросов, и так по 300 раз на 7 типов ошибок. Когда ошибки распознаны верно, бот возвращает к слабому месту в 81% вопросов, а случайный выбор дал бы 45%. Первый прогон показал, что выбор вопросов почти не отличается от случайного, и я его переделал. Это синтетика, а не живые пользователи.
- Тот же скрипт проверяет подсчёт слов-паразитов: в обычных фразах 14 из 15 точно. В ловушках вроде «задачи такого типа» бот ошибается, потому что считает слово по форме, а не по смыслу.

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install faster-whisper      # если нужны голосовые
cp .env.example .env            # вписать BOT_TOKEN и ANTHROPIC_API_KEY
python tools/check_keys.py      # проверит, что ключи рабочие
python bot.py
```

На сервер (Ubuntu) бот ставится одной командой, она сама спросит ключи и запустит службу:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/qbetwyy/kompas-bot/main/deploy.sh)
```

## Данные

Бот хранит только Telegram ID и историю тренировок. Имени и контактов не спрашивает, голосовые никуда не пересылает. Команда `/forget` удаляет всё.

Советы бота, справочные, а не официальная консультация: правила вузов и работодателей меняются, важное лучше перепроверять у них.
